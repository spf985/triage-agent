【头痛】
- 突发剧烈头痛（雷击样），伴呕吐、颈项强直 → 急诊神经内科 → 立即急诊
- 头痛伴发热、颈部僵硬 → 急诊内科 → 立即急诊
- 头痛伴鼻塞、脓涕 → 耳鼻喉科 → 门诊
- 头痛在疲劳、紧张时加重 → 神经内科 → 门诊
- 头痛由外伤引起 → 神经外科 → 尽快就诊
- 头痛伴视力模糊、眼胀 → 眼科 → 尽快就诊

【胸痛】
- 胸骨后压榨性疼痛，放射至左肩、下颌，伴出汗 → 急诊心内科 → 立即急诊
- 胸痛伴呼吸困难、咯血 → 急诊呼吸科 → 立即急诊
- 胸痛伴撕裂样剧痛，向背部放射 → 急诊心血管外科 → 立即急诊
- 劳累后胸痛，休息可缓解 → 心内科 → 尽快就诊
- 胸痛伴反酸、烧心，进食后加重 → 消化内科 → 门诊

【腹痛】
- 右下腹转移性疼痛伴压痛 → 急诊外科 → 尽快就诊
- 上腹疼痛伴反酸、烧心 → 消化内科 → 门诊
- 女性下腹痛伴停经 → 急诊妇产科 → 立即急诊
- 腹痛伴尿急、尿频、尿痛、血尿 → 泌尿外科 → 门诊
- 腹痛伴发热、黄疸 → 急诊外科 → 尽快就诊
- 全腹剧痛、板状腹 → 急诊外科 → 立即急诊

【发热】
- 体温 ≥39℃ 持续 >3 天 → 发热门诊/内科 → 尽快就诊
- 发热伴咳嗽、咳痰、胸痛 → 呼吸内科 → 门诊
- 发热伴皮疹 → 感染科/皮肤科 → 门诊
- 儿童发热 >38℃ 伴精神萎靡 → 儿科急诊 → 立即急诊
- 发热伴意识障碍 → 急诊内科 → 立即急诊

【咳嗽】
- 咳嗽超过3周，伴咯血、消瘦 → 呼吸内科 → 尽快就诊
- 咳嗽伴喘息、呼吸困难 → 呼吸内科/急诊 → 尽快就诊
- 咳嗽伴发热、黄痰 → 呼吸内科 → 门诊
- 夜间咳嗽加重，伴反酸 → 消化内科 → 门诊

【头晕】
- 头晕伴言语不清、肢体无力 → 急诊神经内科 → 立即急诊
- 头晕伴耳鸣、听力下降 → 耳鼻喉科 → 门诊
- 头晕伴心慌、出汗 → 心内科 → 门诊
- 体位改变时头晕 → 神经内科 → 门诊

【腹泻】
- 腹泻伴高热、脓血便 → 急诊消化科 → 尽快就诊
- 腹泻伴严重脱水（口干、尿少、乏力） → 急诊内科 → 立即急诊
- 腹泻超过2周 → 消化内科 → 门诊
- 腹泻伴皮疹 → 感染科 → 门诊

【皮疹】
- 皮疹伴呼吸困难、喉头水肿 → 急诊 → 立即急诊
- 皮疹伴发热 → 感染科/皮肤科 → 门诊
- 皮疹伴关节痛 → 风湿免疫科 → 门诊
- 局部皮疹伴瘙痒 → 皮肤科 → 门诊
